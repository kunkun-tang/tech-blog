## 先把问题说清楚

假设我们收到一组名字，希望去掉首尾空格、统一小写，并过滤空白字符串。先明确输入和输出，再写代码，往往比直接开始更省时间。

> 一个小函数也值得有清楚的边界：它接受什么，返回什么，哪些情况需要调用者处理。

## 写一个简单的实现

```python
def normalize_names(names):
    return [
        name.strip().lower()
        for name in names
        if name.strip()
    ]


raw_names = ["  Alice ", "BOB", "  "]
print(normalize_names(raw_names))
```

结果是 `['alice', 'bob']`。这段实现假设输入元素都是字符串；如果数据来自外部接口，需要先确认数据类型。

## 留意几个边界

| 输入 | 输出 | 说明 |
| --- | --- | --- |
| `"  Alice "` | `"alice"` | 去掉首尾空格并转为小写 |
| `"BOB"` | `"bob"` | 统一大小写 |
| `"  "` | 被过滤 | 空白名字不进入结果 |

处理数据时，可以依次检查：

1. 输入格式是否明确。
2. 空值和空白值如何处理。
3. 是否需要保留原始数据。
